# Wizard answers

These answers demonstrate the input contract only. Run intake against your own repository,
then use its generated questions to replace every example value. The topology is a declared
fictional boundary, not architecture discovered by code inspection.

`answers.json` selects the LATO reference. For a full ATO security-baseline draft, set `mode`
to `ato` and `baseline` to an owner-selected `low`, `moderate` or `high`. The scope confirmation
must be an actual owner's answer in a real project, not inherited from this fixture.

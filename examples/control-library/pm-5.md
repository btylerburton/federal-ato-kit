# PM-5 — System Inventory

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

OMB A-130 (catalog reference: `#27847491-5ce1-4f6a-a1e4-9e483782f0ef`) provides guidance on developing systems inventories and associated reporting requirements. System inventory refers to an organization-wide inventory of systems, not system components as described in CM-8 (catalog reference: `#cm-8`).

### Requirements and exact statement parts

- `pm-5_smt`: Develop and update [PARAM pm-05_odp] an inventory of organizational systems.

# SC-45.1 — Synchronization with Authoritative Time Source

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Synchronization of internal system clocks with an authoritative source provides uniformity of time stamps for systems with multiple system clocks and systems connected over a network.

### Requirements and exact statement parts

- `sc-45.1_smt`: Statement grouping; see child parts.

- `sc-45.1_smt.a`: Compare the internal system clocks [PARAM sc-45.01_odp.01] with [PARAM sc-45.01_odp.02] ; and

- `sc-45.1_smt.b`: Synchronize the internal system clocks to the authoritative time source when the time difference is greater than [PARAM sc-45.01_odp.03].

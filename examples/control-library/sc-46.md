# SC-46 — Cross Domain Policy Enforcement

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

For logical policy enforcement mechanisms, organizations avoid creating a logical path between interfaces to prevent the ability to bypass the policy enforcement mechanism. For physical policy enforcement mechanisms, the robustness of physical isolation afforded by the physical implementation of policy enforcement to preclude the presence of logical covert channels penetrating the security domain may be needed. Contact ncdsmo@nsa.gov (catalog contact: `mailto:ncdsmo@nsa.gov`) for more information.

### Requirements and exact statement parts

- `sc-46_smt`: Implement a policy enforcement mechanism [PARAM sc-46_odp] between the physical and/or network interfaces for the connecting security domains.

# SI-13.4 — Standby Component Installation and Notification

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Automatic or manual transfer of components from standby to active mode can occur upon the detection of component failures.

### Requirements and exact statement parts

- `si-13.4_smt`: If system component failures are detected:

- `si-13.4_smt.a`: Ensure that the standby components are successfully and transparently installed within [PARAM si-13.04_odp.01] ; and

- `si-13.4_smt.b`: [PARAM si-13.04_odp.02].

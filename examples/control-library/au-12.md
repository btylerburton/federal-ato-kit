# AU-12 — Audit Record Generation

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Audit records can be generated from many different system components. The event types specified in AU-2d (catalog reference: `#au-2_smt.d`) are the event types for which audit logs are to be generated and are a subset of all event types for which the system can generate audit records.

### Requirements and exact statement parts

- `au-12_smt`: Statement grouping; see child parts.

- `au-12_smt.a`: Provide audit record generation capability for the event types the system is capable of auditing as defined in AU-2a (catalog reference: `#au-2_smt.a`) on [PARAM au-12_odp.01];

- `au-12_smt.b`: Allow [PARAM au-12_odp.02] to select the event types that are to be logged by specific components of the system; and

- `au-12_smt.c`: Generate audit records for the event types defined in AU-2c (catalog reference: `#au-2_smt.c`) that include the audit record content defined in AU-3 (catalog reference: `#au-3`).

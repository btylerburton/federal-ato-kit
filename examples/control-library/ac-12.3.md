# AC-12.3 — Timeout Warning Message

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

To increase usability, notify users of pending session termination and prompt users to continue the session. The pending session termination time period is based on the parameters defined in the AC-12 (catalog reference: `#ac-12`) base control.

### Requirements and exact statement parts

- `ac-12.3_smt`: Display an explicit message to users indicating that the session will end in [PARAM ac-12.03_odp].

# SI-10.2 — Review and Resolve Errors

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Resolution of input validation errors includes correcting systemic causes of errors and resubmitting transactions with corrected input. Input validation errors are those related to the information inputs defined by the organization in the base control ( SI-10 (catalog reference: `#si-10`)).

### Requirements and exact statement parts

- `si-10.2_smt`: Review and resolve input validation errors within [PARAM si-10.2_prm_1].

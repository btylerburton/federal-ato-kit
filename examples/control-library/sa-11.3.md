# SA-11.3 — Independent Verification of Assessment Plans and Evidence

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Independent agents have the qualifications—including the expertise, skills, training, certifications, and experience—to verify the correct implementation of developer security and privacy assessment plans.

### Requirements and exact statement parts

- `sa-11.3_smt`: Statement grouping; see child parts.

- `sa-11.3_smt.a`: Require an independent agent satisfying [PARAM sa-11.03_odp] to verify the correct implementation of the developer security and privacy assessment plans and the evidence produced during testing and evaluation; and

- `sa-11.3_smt.b`: Verify that the independent agent is provided with sufficient information to complete the verification process or granted the authority to obtain such information.

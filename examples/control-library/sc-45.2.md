# SC-45.2 — Secondary Authoritative Time Source

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

It may be necessary to employ geolocation information to determine that the secondary authoritative time source is in a different geographic region.

### Requirements and exact statement parts

- `sc-45.2_smt`: Statement grouping; see child parts.

- `sc-45.2_smt.a`: Identify a secondary authoritative time source that is in a different geographic region than the primary authoritative time source; and

- `sc-45.2_smt.b`: Synchronize the internal system clocks to the secondary authoritative time source if the primary authoritative time source is unavailable.

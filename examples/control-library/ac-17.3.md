# AC-17.3 — Managed Access Control Points

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Organizations consider the Trusted Internet Connections (TIC) initiative DHS TIC (catalog reference: `#4f42ee6e-86cc-403b-a51f-76c2b4f81b54`) requirements for external network connections since limiting the number of access control points for remote access reduces attack surfaces.

### Requirements and exact statement parts

- `ac-17.3_smt`: Route remote accesses through authorized and managed network access control points.

# PS-6.2 — Classified Information Requiring Special Protection

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Classified information that requires special protection includes collateral information, Special Access Program (SAP) information, and Sensitive Compartmented Information (SCI). Personnel security criteria reflect applicable laws, executive orders, directives, regulations, policies, standards, and guidelines.

### Requirements and exact statement parts

- `ps-6.2_smt`: Verify that access to classified information requiring special protection is granted only to individuals who:

- `ps-6.2_smt.a`: Have a valid access authorization that is demonstrated by assigned official government duties;

- `ps-6.2_smt.b`: Satisfy associated personnel security criteria; and

- `ps-6.2_smt.c`: Have read, understood, and signed a nondisclosure agreement.

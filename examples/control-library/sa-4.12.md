# SA-4.12 — Data Ownership

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Contractors who operate a system that contains data owned by an organization initiating the contract have policies and procedures in place to remove the data from their systems and/or return the data in a time frame defined by the contract.

### Requirements and exact statement parts

- `sa-4.12_smt`: Statement grouping; see child parts.

- `sa-4.12_smt.a`: Include organizational data ownership requirements in the acquisition contract; and

- `sa-4.12_smt.b`: Require all data to be removed from the contractor’s system and returned to the organization within [PARAM sa-04.12_odp].

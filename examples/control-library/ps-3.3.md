# PS-3.3 — Information Requiring Special Protective Measures

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Organizational information that requires special protection includes controlled unclassified information. Personnel security criteria include position sensitivity background screening requirements.

### Requirements and exact statement parts

- `ps-3.3_smt`: Verify that individuals accessing a system processing, storing, or transmitting information requiring special protection:

- `ps-3.3_smt.a`: Have valid access authorizations that are demonstrated by assigned official government duties; and

- `ps-3.3_smt.b`: Satisfy [PARAM ps-03.03_odp].

# SI-10.1 — Manual Override Capability

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

In certain situations, such as during events that are defined in contingency plans, a manual override capability for input validation may be needed. Manual overrides are used only in limited circumstances and with the inputs defined by the organization.

### Requirements and exact statement parts

- `si-10.1_smt`: Statement grouping; see child parts.

- `si-10.1_smt.a`: Provide a manual override capability for input validation of the following information inputs: [PARAM si-10_odp];

- `si-10.1_smt.b`: Restrict the use of the manual override capability to only [PARAM si-10.01_odp] ; and

- `si-10.1_smt.c`: Audit the use of the manual override capability.

# AC-17.1 — Monitoring and Control

## Catalog-grounded response guidance

Template guidance only. This material does not establish implementation, applicability, inheritance, or assessment status.

### Control-specific description (catalog guidance)

Monitoring and control of remote access methods allows organizations to detect attacks and help ensure compliance with remote access policies by auditing the connection activities of remote users on a variety of system components, including servers, notebook computers, workstations, smart phones, and tablets. Audit logging for remote access is enforced by AU-2 (catalog reference: `#au-2`) . Audit events are defined in AU-2a (catalog reference: `#au-2_smt.a`).

### Requirements and exact statement parts

- `ac-17.1_smt`: Employ automated mechanisms to monitor and control remote access methods.
